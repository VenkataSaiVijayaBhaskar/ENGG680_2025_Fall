\## Assignment Overview



This lab assignment covers advanced concepts in digital engineering, focusing on \*\*Non-linear Estimation and Machine Learning\*\*. The project combines optimization theory with practical deep learning implementation to solve real-world positioning and classification problems.



\*\*Key Topics Covered:\*\*



\*\*Part 1: Non-linear Least Squares Estimation \& Gradient Descent\*\* - Implements parameter estimation techniques using Least Square methods and Gradient Descent algorithms applied to Single Point Positioning (SPP) problems. We compare convergence rates, computational efficiency, and accuracy between LSE and iterative gradient-based approaches, demonstrating how optimization algorithms minimize residual errors in pseudorange observations.



\*\*Part 2: Machine Learning \& Deep Neural Networks\*\* - Builds and trains Multi-Layer Perceptron (MLP) and Convolutional Neural Network (CNN) architectures on the MNIST digit dataset. This section explores neural network fundamentals including backpropagation, training curves, accuracy metrics, and the advantages of convolutional layers for image classification. Model performance is systematically evaluated and compared.



\*\*Part 3: Comparative Analysis \& Model Evaluation\*\* - Analyzes prediction patterns between both classifiers, identifying cases where models agree or disagree. Visualizes correct and incorrect predictions to provide empirical insights into model behavior, generalization capabilities, and the practical trade-offs between different optimization strategies.
