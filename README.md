Our lab assignment covers Python programming fundamentals (data structures, classes, Pandas) and applies linear least squares estimation (LSE) to fit polynomial curves to noisy data. The assignment includes working with CSV files containing student data (English grades, Math grades, and homeroom assignments) to build a Student Gradebook Management System using Pandas for data analysis. The main focus is implementing LSE algorithms, comparing different polynomial degrees (2nd, 4th, 6th order), and analyzing the differences between weighted and unweighted approaches to evaluate goodness of fit.
